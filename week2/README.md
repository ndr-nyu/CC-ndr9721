## Assignment Notes

With my original sketches, I intended to have an array of the same type of shape that gradually increased in width. When the user clicks, a set of different shapes start growing from the bottom of the screen and eventually push the top shape out of sight. I wanted it to continue looping and cycle through ellipses to rectangles to triangles. After I was able to get this concept into code, it felt a little boring and so I added a rotation to spice it up. Also, the requirement to add a new color palette with every click made the graphic a lot more dynamic. I decided to add instructions as well so that I could send this to anyone and they would know what to do.
