# week3 Notes

For the first iteration, try clicking and drag-clicking your mouse for some fun features. ‘Waves’ took a lot of trial and error in testing out the y-axis wave and getting the ripples to look how I wanted. The LLM was able to help me smooth out the graphic effects to flow with the rest of the wave action.

For the second iteration, test out clicking your mouse for a built-in function. ‘Swivel’ was my simplest idea, the easiest sketch to put in code and also my favorite end result. I like the cleanness to this aesthetic compared to the more complicated ideas.

The third iteration has no special mouse click or drag-click features — just move your mouse around the screen for the visual effects. ‘Glow’ was my hardest iteration I worked on. I had to pivot completely from my original idea because it wasn’t panning out. I was trying to create repeating diagonal lines that spanned the entire screen, then the lines would split into multiple smaller lines from every other y-axis column slowly moving up and down. After testing out so many different iterations using the LLM, I had to call it quits. Unfortunately it was also too late to get Bo’s guidance on this one. I ended up pivoting to what you see on the screen now as ‘glow’ and this was much simpler.

Was it was failing because you can’t create a “continuous” looking line with a 2D for loop?

## Getting Started

## Running Locally

For projects with media files, use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server

# Using VS Code Live Server extension
# Right-click index.html -> "Open with Live Server"
```
